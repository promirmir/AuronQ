Jak tworzone są peery

Node startuje z bootstrap peerami, uczy się kolejnych przez P2P i zapisuje publiczny peer store.
Podczas kopania z włączoną opcją publicznego noda aplikacja tworzy mapowanie UPnP TCP/18444 i wysyła ogłoszenie do peerów, które wykonują callback-verification.
Jeśli operator ma CGNAT lub router bez UPnP, node pozostaje outbound-only. Nadal waliduje, kopie, synchronizuje i przekazuje bloki przez połączenia wychodzące.
