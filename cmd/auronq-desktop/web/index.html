AUTO P2P
Normalnie niczego nie konfigurujesz. AuronQ używa DNS/static bootstrapów z network.json tylko do znalezienia pierwszych nodów, potem poznaje kolejne przez P2P, zapisuje cache peerów i automatycznie próbuje ogłosić własny publiczny port 18444.
Opcje zaawansowane / awaryjny peer
