# Historical AuronQ material

This directory keeps older release notes, checksums and pre-mainnet release-candidate documents for provenance.

They are **not recommended downloads** and are intentionally kept out of the repository root so the current project state is easier to understand.

## Archive layout

- `releases/` — detailed historical `CHANGES-*` files.
- `checksums/` — historical checksum files that predate the current release pages.
- `rc/` — release-candidate notes, old startup documents and early build verification.

For supported/current downloads use:

- [AuronQ Releases](https://github.com/promirmir/AuronQ/releases)
- [Current README](../../README.md)
- [Consolidated changelog](../../CHANGELOG.md)
