AuronQ

An open-source experimental cryptocurrency network built around independent full-node validation, a UTXO ledger, AQM64 Proof-of-Work and ML-DSA-87 post-quantum transaction signatures.

Download latest release Source code Protocol
Full-node firstEvery full node validates its own canonical chain, transactions, signatures, timestamps, difficulty and cumulative work.
Post-quantum transaction signaturesWallet transactions use ML-DSA-87. This does not by itself imply that the entire system is quantum-proof.
AQM64 Proof-of-WorkAuronQ uses its own AQM64 PoW construction and cumulative-work chain selection.
Local ExplorerEach full node serves its own read-only blockchain Explorer from locally validated data.

Decentralization model

No privileged founder nodeSeed peers are replaceable discovery hints. They do not have consensus authority and repeated failures can prune them.
Native peer discoveryNodes persist learned peers and exchange verified public peer information through the AuronQ P2P network.
No canonical ExplorerPublic Explorers are ordinary full-node views. Peer-aware Explorers can link to alternative public full-node Explorers.
Independent validationPeer identity is not trust. Nodes validate the data they accept and choose chains by validated cumulative work.

Engineering progress

The project includes 20-node partition/reorg/restart convergence testing, transaction/block fuzzing, Linux race-detector CI, reproducible-build checks, public-network health monitoring, peer-netgroup diversity and a regression test in which the original bootstrap node disappears permanently.

Security status

Experimental and not independently audited AQM64 and the complete consensus/network implementation have not received an independent professional security or cryptographic audit. Internal tests and CI are not a substitute for external review. Do not use substantial value.
