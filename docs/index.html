AuronQ

Open-source experimental post-quantum Proof-of-Work cryptocurrency.

About the network

AuronQ uses ML-DSA-87 for transaction signatures, a UTXO accounting model and the AQM64 Proof-of-Work construction. Full nodes validate the canonical chain locally and expose a built-in blockchain explorer.

Security status

AuronQ is experimental software. AQM64 and the complete consensus/network implementation have not received an independent professional security or cryptographic audit.
