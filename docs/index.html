AuronQ. A network you can verify.

AuronQ (AURQ) is an open-source UTXO cryptocurrency built in Go. It combines independent full-node validation, AQM64 Proof-of-Work and ML-DSA-87 transaction signatures.

Independent network operation

AuronQ is designed around nodes that validate rules locally. Current source can discover, verify, persist and exchange peers without requiring GitHub at runtime, while CLI/miner clients can fail over across verified Mainnet endpoints. Bootstrap metadata helps first contact; it does not control consensus. A witnessed founder-offline clean-install drill is still required before claiming complete operational independence.

Verify for yourself

  • Full nodes validate blocks, transactions, signatures and cumulative work independently.
  • Each full node can serve a read-only Explorer from its own chain.
  • Network identity and consensus details are documented publicly.

Solo mining is supported. Independent pools and third-party miners are separate services; check their fees, safety and availability with each operator.

Security and maturity

AuronQ is a young public network. AQM64 and the complete consensus, wallet and networking implementations have not received an independent professional security or cryptographic audit. ML-DSA-87 is a standardized signature algorithm; using it does not prove the complete system is post-quantum secure. Avoid storing or transferring substantial value until independent review and longer operational testing are complete.
