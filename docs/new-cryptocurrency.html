AuronQ (AURQ) — a new Proof-of-Work cryptocurrency in 2026

If you are searching for a new cryptocurrency, a new mineable crypto project or a new Proof-of-Work coin that can be independently inspected, AuronQ is a public open-source network with its own blockchain, full nodes, wallets, mining and Explorer.

AuronQ is not a token deployed on another blockchain. The network uses a UTXO ledger, AQM64 Proof-of-Work and ML-DSA-87 transaction signatures.

What kind of new crypto is AuronQ?

Can AURQ be mined?

Yes. AURQ is a mineable Proof-of-Work cryptocurrency. The project supports solo CPU mining, and independent third-party mining infrastructure is available. Current public options include MeshPool and RPlant. Third-party services are independently operated, so miners should verify current fees, payout rules and binaries themselves.

Is this an investment page?

No. AuronQ is presented here as a new open-source cryptocurrency network that can be run, mined, inspected and reviewed. There is no promise of price appreciation, exchange listing or financial return. The useful question at this stage is whether the software and network behave correctly under independent use.
