# AuronQ (AURQ)

AuronQ is a Bitcoin-inspired, UTXO-based, proof-of-work cryptocurrency designed from genesis around post-quantum transaction signatures.

This repository is being prepared for the AuronQ 1.7.0-rc4 public release.

> Security status: the implementation passes its included Go test/vet suites and deterministic crypto vectors, but AQM64 is a new consensus construction and has **not** received an independent security/cryptographic audit. Do not attach material real-world value to a public mainnet before independent review.
