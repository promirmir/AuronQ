AuronQ Desktop / Node 1.3.0

- Removed Tailscale from the normal Desktop networking path.
- Public Internet bootstrap now comes from seed_peers in network.json.
- Added persistent cache for learned public P2P peers.
- Added bounded public peer gossip (max 64 known; max 32 advertised).
- Added /p2p/announce for publicly reachable nodes. Announcements are network-ID checked and probed before acceptance.
- Learned gossip rejects loopback, private and 100.64.0.0/10 carrier-NAT addresses.
- Seed/manual peers remain allowed for local development and recovery.
- Added network-set-seeds CLI command; changing seed_peers does not change Network ID.
- Desktop binds its full node on TCP 18444 and requires no manual peer entry when network.json contains working public seeds.
- Chain and mempool synchronization interval reduced to 10 seconds.
- Added PUBLIC-NETWORK.md deployment guide.
