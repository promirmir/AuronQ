AuronQ 1.7.0 Mainnet

- Promotes the tested rc4 consensus/network code to public mainnet version 1.7.0 without changing genesis or Network ID.
- Keeps persistent peer storage, peer gossip, fixed seeds, DNS seeds and bounded HTTPS bootstrap manifests.
- Publishes the official bootstrap manifest at the stable GitHub raw URL.
- The manifest currently advertises one confirmed public Tailscale Funnel endpoint fronting an ordinary full node; it has no consensus privileges.
- Additional independent public nodes and DNS seeds remain an operational priority.
- Windows package includes START-AURONQ.cmd for normal users and START-SEED-NODE.cmd for bootstrap operators.
- Retains the same-branch catch-up repair verified in a live two-node test through height 5.
